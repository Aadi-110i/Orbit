# Product Hunt

**Name:** Orbit
**Tagline:** Run Claude, GPT and Gemini side by side on one infinite canvas

**Description (paste into the "What it does" box):**

> Orbit replaces your browser tabs with a single infinite canvas. Every AI chat,
> note, code file and diagram is a window you place exactly where it belongs.
>
> The workflow it was built for: ask three models the same question, compare
> the answers, keep the best one next to your code. Instead of scrolling
> through chat histories to recover context, you *see* your context.
>
> - 7 providers — OpenAI, Anthropic, Gemini, Mistral, OpenRouter, DeepSeek,
>   Perplexity — with per-window model selection
> - Streaming responses over SSE, Markdown rendering
> - Monaco editor (15 languages) as a window on the board
> - Notes with autosave, freeform drawing with undo
> - Radar minimap, command palette, keyboard shortcuts
> - No sign-up. Your board is saved in your browser. Bring your own API key —
>   it never touches a server.
>
> Free and open source (MIT).
